# CLASH OF CHAMPIONS — Ultimate Edition

Объединённая версия браузерного файтинга с 14 персонажами, 5 аренами, конструктором авторских приёмов и трёхфазным РТ Араи.

## Как запустить

1. Распакуй весь ZIP, сохранив структуру папок.
2. Открой `index.html` в Chrome, Edge или Firefox. Все обычные режимы работают без сервера.
3. Для онлайн-комнат нужен интернет: библиотека PeerJS подгружается при создании или подключении к комнате. Надёжность сетевого режима зависит от соединения и сервера сигнализации.

Также есть отдельная одностраничная сборка `Clash_of_Champions_Ultimate.html`: она включает исходные изображения прямо в HTML без потери качества.

## Что объединено

- Из `clash-of-champions(1).html`: интерфейс, 14 персонажей, 5 арен, 11 правил, 6 режимов, конструктор приёмов, настраиваемое управление, пользовательская музыка, РТ с Q-прицеливанием и шкалой АТАКИ.
- Из `index(1).html`: ситуативная логика ИИ, веса приёмов для каждого персонажа, защитные решения против ударов и снарядов, идеи индивидуальных взаимодействий способностей.
- Из `Clash_of_Champions_Source(1).zip`: раздельная структура основных подсистем, чтобы обычный бой и РТ можно было расширять независимо.
- Из `characters.zip`: 14 оригинальных изображений, включая `onsoku.jpg` (в игре — `sonic.jpg`). Все JPEG/PNG скопированы побайтно: ни пережатия, ни изменения размеров, ни уменьшения разрешения нет. CSS использует `object-fit: contain`, сохраняя пропорции.

## Обычные режимы и РТ

- Обычный бой: против ИИ, аркада, выживание, тренировка, локальный бой, онлайн.
- ИИ: лёгкий, обычный и сложный. Дистанция, возможные снаряды, блоки и характер способности влияют на решение.
- РТ: три фазы; при игре против Араи открывается после 100% шкалы, отдельная кнопка позволяет испытать сразу. `Q` меняет цель, Shift или двойное направление — рывок, Space — огонь.
- За близкий проход около вражеского снаряда увеличивается шкала АТАКИ и сокращается перезарядка первого приёма. Шкала не сбрасывается после попадания, а применение щита не запрещает её пополнять.
- Способности 14 персонажей в РТ теперь имеют отдельные обработчики в `src/rt-abilities.js`: орбиты Ляписа, призывы, кровотечение, лечение, контратаки, шикигами и другие адаптации. Это игровые интерпретации, а не буквальный перенос каждого физического взаимодействия из обычного боя.

## Структура

| Путь | Назначение |
| --- | --- |
| `src/core.js` | Герои, настройки, управление, музыка |
| `src/app.js` | Меню и конструктор |
| `src/fight.js` | Движок обычного боя |
| `src/ai-enhanced.js` | Ситуативный ИИ |
| `src/combat-refinements.js` | Отражение снарядов орбитами и перехват снарядов призывами |
| `src/rt.js` | РТ Араи |
| `src/rt-abilities.js` | Адаптации способностей всех героев в РТ |
| `src/portraits.js` | Галерея и выбор портретов |
| `src/network.js` | Сетевые комнаты |
| `assets/portraits/` | Оригинальные изображения |

Для будущего нового РТ удобно создавать новый контроллер рядом с `rt.js` и подключать его из приложения, не вмешиваясь в обычную симуляцию. Реестр навыков находится в `RT_SKILL_HANDLERS`.

## Проверка исходников

`node tests/logic.test.cjs` проверяет наличие всех портретов, разбор JavaScript, 14 профилей ИИ и использование активных RT-способностей. Тест не заменяет игровые испытания в реальном браузере.
